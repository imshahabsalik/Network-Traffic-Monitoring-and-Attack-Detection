# Network Traffic Monitoring and Attack Detection

## Project Overview
This project aims to develop a real-time network traffic monitoring and attack detection system using Python.

## Objectives
- Capture and analyze network packets.
- Monitor network traffic patterns.
- Detect suspicious activities such as port scanning, brute force attacks, and DoS attacks.
- Generate alerts and reports.
- Provide a dashboard for visualization.

## Technologies
- Python
- Scapy
- Flask
- SQLite
- Chart.js
